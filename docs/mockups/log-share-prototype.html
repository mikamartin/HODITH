try other values

Recommendation: 30 — matches the Log tab's own existing initial page size (spec §6: 30 events, then “Show more” in batches of 50). Familiar number, not an arbitrary new one. Square's own space already trims lower than this for most cases.

Decided Entry point: Option B — single Share icon opening an AlertDialog chooser (section 1).

Still open

  1. Format: given both formats are now capped, does Square still earn its place for a log — or Story-only?
  2. Defaults: sort direction, date range, and which fields start on? Leaning: newest-first, full history, all applicable fields on — matches how Insight Share defaults (everything on, user trims).
  3. Cap value & behavior: is 30 right, and should it silently truncate (as built) or block sharing until the range is narrowed?
  4. Reuse: section 4 now mirrors Big Picture exactly — FilterTriggerChips for Sort/Range, a pinned Edit icon for which fields show — right shape for the Log tab?

4 · Same filter, on the Log tab

Two borrowed patterns, not one: Sort/Range are true filters (what's included), shown as Big Picture's collapsed FilterTriggerChips (“Cases: 2 of 3 ▸”) — a better fit for a screen you look at constantly, usually with nothing narrowed. Which fields a row shows isn't a filter, it's per-row content — Big Picture already draws that exact line, editing its own per-row detail fields via a pinned-right Edit icon (BigPictureDetailField), not a third chip.
