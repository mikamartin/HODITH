Big Picture — year filter

Kept to just the year-filter direction now that it's the one being pursued — the other two candidates (year rail, year-summary zoom) are dropped from this file to avoid confusion. Shown against a synthetic ~2.75-year, 3-Case dataset (Jan 2024–Sep 2026), with the existing Cases/Tags filter row and legend reproduced for context since Year has to sit alongside them. All copy here is illustrative, not final Voice-layer strings.

Settled so far

  • A third trigger chip, Year, joins Cases/Tags in the existing filter row and opens the same kind of picker dialog.
  • Only appears when there's more than one year of data — a one-value filter is dead weight, same reasoning as the existing Tags chip's own conditional.
  • Defaults to All years; picking one narrows the grid to just that year's months, with an explicit reset back to All.
  • Cases/Tags/Year all get a border on their chip whenever they're off their default (not all selected, or a specific year), so an active filter is visible at a glance.
  • The Year dialog lists current year first, oldest last; the month grid itself now opens on today at the top, scrolling downward into the past — a deliberate reversal of the shipped app's oldest-top/current-bottom order (spec §9), being tried here, not yet a spec change.
  • Cases/Tags/Year chips read "Label: value" (e.g. "Cases: 2", "Tags: All"), not "N of M".
